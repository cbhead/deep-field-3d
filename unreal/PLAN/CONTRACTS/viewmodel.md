# C12 — UI view models

**Canonical:** `unreal/DeepField/Source/DFUI/Public/ViewModels/*.h` (UE MVVM `UMVVMViewModelBase` subclasses). **Owner:** WS-12. **Rule:** A for new fields; R for rename/remove. Mirrors `game/scripts/ui/GameView.cs`: **every widget reads only these; no widget or view model calls `HasAuthority()` / `GetNetMode()`** (CI grep on `Source/DFUI`).

`UDFMatchViewModel` — `Money, Lives, WaveIndex, TotalWaves, Phase, PhaseSecondsLeft, bLobby, bEndless, Threat, EnemiesRemaining, TeamScrap{}, ActiveCondition, NextCondition, Tier, BestWave, PendingSpend, Boss{bActive, Phase, HpFrac, Plates}, Players[] (UDFPlayerViewModel), Structures[] (UDFStructureViewModel), Pickups[], Vehicles[], LaneGateStates{}, MutableStates{}, ConnectionState, EarlyCallVotes{}, Pings[]`; helpers `Local()`, `AtSocket(FName)`, `TeamScrapOf(type)`, `PersonalScrapOf(player,type)`, `SeatOf(player)`.

`UDFPlayerViewModel` — `PlayerId, Name, Faction, FactionLevel, Position, Hp, MaxHp, bDowned, bConnected, ReviveProgress, BleedoutSecondsLeft, Weapon, Melee, AbilityCooldownFrac, Scrap{}, MatchXp, Kills, DamageDealt, TowersBuilt, Revives, OwnedWeapons[], CraftedAmmo[], Builds{} (FDFWeaponBuild), Seat, bHost, bCarrying, bDragging, bInNest`.

`UDFStructureViewModel` — `StructureId, DefTag, SocketId, OwnerPlayerId, PathLevels[3], bTrap, Charges, HpFrac, Heat, FedBy, bSellable (per ownership rules)`.

`UDFPickupViewModel` — `Id, ScrapType, Position, SecondsLeft, bPersonal`. `UDFVehicleViewModel` — `VehicleId, DefTag, Position, Yaw, Seats[], HpFrac, bWreck`.

Sources: `ADFMatchState`, the `ADFPlayerState` array, structure/pickup/vehicle actors — **replicated properties only**; the listen host reads its own authoritative actors through the same properties, so the code path is identical on host and client. Discrete UI events (toasts, refusals, combo callouts, boss horn) come from `DF.Message.*` subscriptions, never from polling.

## As implemented (WS-12, 2026-09-19)

- **Types.** Content ids are `FName` exactly as the JSON spells them (`Weapon`, `Melee`, `ActiveCondition`, `NextCondition`, `OwnedWeapons[]`, `CraftedAmmo[]`, `Builds` keys, `SocketId`, `VehicleId`) — the key `UDFContentSubsystem` takes. Gameplay tags where the messages already carry tags: `Faction` (`DF.Faction.*`), `Tier` (`DF.Tier.*`), `DefTag` (`DF.Tower.*` / `DF.Trap.*`), `Boss.Phase` (`DF.Boss.Phase.*`), and **`ConnectionState` = the tag of the last `DF.Message.ConnectionState` payload** (`FDFMsg_Tagged.Tag`; DFUI cannot see DFOnline's enum — same layer — and does not need to). `Phase` is `EDFMatchPhase` and `Builds` values are `FDFWeaponBuild`, both in `DFCore/Public/Match/DFMatchTypes.h` so DFMatch can replicate them and DFGameplay can compute with them. `TeamScrap` / `Scrap` are `TMap<EDFScrapType,int32>`; `LaneGateStates` is gate id → open; `MutableStates` is mutable id → state id; `EarlyCallVotes` is PlayerId → voted; `Seat` is the seat index (−1 on foot; `SeatOf` names the vehicle).
- **Fields appended (rule A):** match `bValid`, `LocalPlayerId`, `Lap` (2026-09-27: endless laps completed, `ADFMatchState::GetLap`, for the HUD's "Endless, lap N"); match `bRestartPending` (2026-09-27: a new match follows this finished one, `ADFMatchState::IsRestartPending`; with `PhaseSecondsLeft` 0 it means the host is loading it); player `AmmoInMagazine`, `MagazineSize` (0 = no gun), `bReloading`, `ReloadFrac` (2026-09-27: WS-03's `UDFHeroWeaponComponent`, owner-predicted, so exact for the local hero only); player `BuildChoice` (2026-09-27: the towers.json id hold-E builds, from the local `ADFPlayerController`; None for other players); structure and vehicle `DefId` (the content id beside `DefTag`; the `DF.Vehicle.*` root landed 2026-09-25 with ruling R10 and is in `tags.md`, so `DefTag` resolves via `DFTags::ForContentId("DF.Vehicle", VehicleId)` — `DefId` remains the `UDFContentSubsystem` key); pickup `Amount`. Derived, notifying: player `HpFrac()`; match `Local()`. Pure helpers: match `FindPlayer`, `AtSocket`, `IsSocketOccupied`, `VehicleById`, `TeamScrapOf`, `PersonalScrapOf`, `SeatOf`, `SpendableMoney` (= `Money − PendingSpend`); player `ScrapOf`, `Owns`, `PackLevelFor`, `AmmoFor`, `AttachmentFor`; structure `PathLevel`; vehicle `SeatOf`, `IsSeatFree`, `DriverId`.
- **Writing.** Fields are private; a feed writes through `Set<Field>` / `Set<Flag>` and a setter notifies only on a real change (maps compare order-independently), so a feed may write everything every frame. Children are **found-or-added by id and keep their identity** (`FindOrAdd*`, `Remove*`, `Retain*({ids})` once per feed pass): a widget bound to one player or tower stays bound. `Reset()` returns the match to its constructed state but keeps `ConnectionState` (the session outlives a match).
- **Where it lives.** `UDFViewModelSubsystem` (game-instance) owns the one `UDFMatchViewModel`, registers it in the MVVM global collection as **`DFMatch`** (a `WBP_` picks it with "Global Viewmodel Collection"), and keeps `ConnectionState` current from the bus. `FDFFakeMatchFeed::{FillMidWave, FillLobby, Tick}` stays as `L_Test_UI`'s feed.
- **The real feed (2026-09-27).** `FDFMatchStateFeed::Fill` copies the world's `ADFMatchState` into the model: WS-28's fields (phase, wave, total, lobby, endless, lap, threat, enemies remaining, and `PhaseSecondsLeft` = this machine's reading of the replicated end time, 0 when the clock is stopped; after Victory / Defeat it is the host's restart clock, the seconds until the new match, which the HUD shows as "New match in 12s" under the banner while `bRestartPending`, then "Starting new match…" at 0 until the map goes — 2026-09-27), WS-06's `UDFEconomyStateComponent` (money, lives), and one `UDFPlayerViewModel` per **seated** `ADFPlayerState` (PlayerId = seat; name, connected, match record, WS-03 hero state: downed, revive fraction, bleedout per R13, vehicle seat; hp / max hp / position from the hero pawn's `UDFHealthSet`). `LocalPlayerId` is the seat of this machine's first local player. `UDFMatchFeedSubsystem` (a tickable world subsystem, Game and PIE worlds) runs it every frame on host and client alike, only when the world's game state is an `ADFMatchState`, and `Reset`s the model when the world goes away. Still default, waiting for their components (ADR-0024): team scrap (host-only until WS-06 replicates it), pending spend, faction and level, loadouts and personal scrap, structures, pickups, vehicles, boss, conditions, gates and mutables, tier, best wave, pings, early-call votes.
