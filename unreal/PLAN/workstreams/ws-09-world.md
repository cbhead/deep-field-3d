## LFS etiquette (ADR-0010)
Every `Content/**/*.uasset` and `*.umap` is `lockable`: git-lfs checks them out **read-only**, and `git lfs lock <repo path>` is what makes one writable. Before editing or re-importing a shared level: `git lfs lock unreal/DeepField/Content/DF/Maps/<Map>/L_<Map>_Gameplay.umap` (and `L_<Map>.umap` when the importer will save it — only when it adds the sublevel); `git lfs unlock` at session end. `-run=DFLevelImport` clears the read-only bit on exactly the packages it saves so a re-import works on a plain checkout, logs each file it made writable, and prints an `LFS reminder (ADR-0010)` line per lockable file — it takes **no** lock; the reminder is the etiquette, not a substitute for it. `DFMapValidate` saves no package (only the text report).

- Legacy air lanes are absolute-Y over a flat floor, so `AglMeters` is the edge's mean height; authored 3D files carry `agl` and will set it directly. Legacy points at y=0 are projected onto `DF_LaneSurface`; anything above grade (decks, wall sockets) keeps its height.
