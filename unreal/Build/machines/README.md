# unreal/Build/machines — what each machine measurably has

Three kinds of session now work on this project: the Mac, the Windows GPU box, and cloud sessions.
They do not have the same hardware or tools, so a session must never assume what another machine can
do. Each machine's capabilities are **measured by a script and committed here**. When you need
something from a machine (a GPU, an engine version, a toolset, disk space), read its file here. Do
not infer it from the plan, a runbook or memory.

| Machine | File | Generated by | Role (ADR-0023) |
|---|---|---|---|
| Windows GPU box | [`windows-gpu.md`](windows-gpu.md) (+ `.json`) | [`../machine-inventory.ps1`](../machine-inventory.ps1) | Nanite/Lumen/VSM, `L_<Map>_Art`, Windows packaging + EOS overlay, perf, Gauntlet, soak, self-hosted CI |
| Mac (M1, 8 GB) | not yet measured | — (a zsh twin of the script is WS-15 work) | Gameplay C++, `-nullrhi` logic tests, content pipeline, graybox, Mac packaging, the 8 GB floor |
| Cloud sessions | not yet measured | — | Plan, text and code work only; assume no engine, no GPU and no LFS art until a file here says otherwise |

## Rules

- **The files are generated. Do not edit them by hand.** Re-run the script after installing,
  upgrading or reconfiguring anything, and commit the `.md` and `.json` together in the same PR as
  the change they reflect.
- **The date in the file is the date of the facts.** If the file is older than the most recent
  install on that machine, re-run it before you rely on it.
- The Windows file also checks the box against every requirement in
  [`../windows-bringup.md`](../windows-bringup.md). Its readiness table shows how far bring-up has
  got. Any `FAIL` in that table means the lane that depends on it is still unverified.
- Some facts need an elevated shell, such as the Defender exclusions. The file says `UNKNOWN`
  rather than guessing. Run the script from an administrator PowerShell once to fill them in.
- Nothing identifying beyond the host name is collected: no serial numbers, IP or MAC addresses, or
  tokens. Keep it that way when adding probes.

## Running it

```bat
powershell -ExecutionPolicy Bypass -File unreal\Build\machine-inventory.ps1
```

Run it from plain PowerShell or `cmd`, **not from Git Bash**. Git Bash puts its own `git`, `python`
and so on on `PATH`, and the report would then say they are on `PATH` for every shell when they are
not. `-NoDxDiag` skips the ~20 s `dxdiag` step. `-Name` changes the output name (for example, a
second Windows machine).
